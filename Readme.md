# 📚 Library Management System (Java OOP Project)

This project is developed as part of **Task 2** for the SWYNEX Internship.
It demonstrates the implementation of core **Object-Oriented Programming (OOP)** concepts in Java through a simple Library Management System.

---

## 🚀 Features

* 📖 Add books to the library
* 📋 View all books with status (Issued / Available)
* 📤 Issue books
* 👤 Display user information (Student / Librarian)

---

## 🧠 OOP Concepts Used

### 🔒 Encapsulation

* Private variables in `Book` class
* Access controlled using getters

### 🧬 Inheritance

* `Student` and `Librarian` inherit from `User`

### 🧩 Abstraction

* `User` is an abstract class

### 🔁 Polymorphism

* `displayInfo()` method is overridden in child classes

---

## 📁 Project Structure

```
SWYNEX-Object-Oriented-Java-Project
│
├── MainApp.java
├── Book.java
├── User.java
├── Student.java
├── Librarian.java
├── Library.java
```

---

## ⚙️ How to Run

1. Open terminal in project folder
2. Compile all files:

```
javac *.java
```

3. Run the program:

```
java MainApp
```
